# Todo (Thai UI)

React + Vite + Tailwind CSS + lucide-react. State is in memory only (no localStorage).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # output in dist/
```

Features: add (Enter / button), complete, delete with animation, double-click to edit,
All / Active / Completed filters, remaining count, clear completed, Low / Medium / High priority.
